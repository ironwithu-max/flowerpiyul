# 메인 히어로 슬라이드쇼 사진

이 폴더에 꽃다발 사진을 넣으면 **홈 화면 상단 슬라이드쇼에 자동으로 추가**되어 3.5초마다 전환됩니다.

- 지원 형식: `.jpg` `.jpeg` `.png` `.webp` `.gif`
- 파일 이름 **알파벳/숫자 순서**대로 재생됩니다 (예: `01.jpg`, `02.jpg` …)
- 권장 비율: 가로형 16:9, 권장 크기 1280×720 이상
- 슬라이드(또는 영역 전체)를 클릭하면 인스타그램 `@flower_piyul`로 이동합니다.

> `sample-*.png` 파일은 임시 예시입니다. 실제 사진을 넣은 뒤 삭제하세요.

## 인스타그램 실시간 연동(선택)

현재는 이 폴더의 사진을 보여주는 방식입니다. 인스타그램에 새 글을 올리면 **자동으로 동기화**되게 하려면 다음 중 하나가 필요합니다.
1. **Instagram Graph API** — 비즈니스/크리에이터 계정 + 액세스 토큰 필요
2. **외부 위젯 서비스** — LightWidget, EmbedSocial, Elfsight 등 (가입 후 위젯 ID 발급)

원하시면 위 방식으로 자동 연동을 붙여드릴 수 있습니다.
